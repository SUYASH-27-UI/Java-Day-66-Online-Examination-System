# Java Day 66 – Online Examination System

## Project Description
A Java-based online examination application that conducts multiple-choice tests, evaluates answers, calculates percentages, assigns grades, and saves student results.

## Features
- Accepts student information.
- Displays multiple-choice questions.
- Checks answers automatically.
- Calculates correct and incorrect answers.
- Calculates examination percentage.
- Assigns grades.
- Exports examination results to CSV.

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- HashMap
- Scanner
- File Handling

## Project Files
- `Main.java` – Main application.
- `exam_results.csv` – Generated examination results.

## Grading System
- 80% or above – A
- 60% to 79% – B
- 40% to 59% – C
- Below 40% – Fail

## How to Run
1. Compile using `javac Main.java`.
2. Run using `java Main`.
3. Enter the student name.
4. Answer the questions.
5. View and save the result.

## Learning Outcomes
Learned OOP, ArrayList, HashMap, automatic evaluation, grade calculation, and CSV file handling.
